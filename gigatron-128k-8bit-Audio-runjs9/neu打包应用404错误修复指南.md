# Neu 打包应用 404 错误修复指南

## 快速修复步骤

### 步骤 1：修改 neutralino.config.json 配置

根据错误日志分析，问题在于资源文件路径映射。请按照以下方式修改 [`neutralino.config.json`](neutralino.config.json) 文件：

```json
{
  "applicationId": "com.gigatron.emulator.neutralino",
  "defaultMode": "window",
  "port": 0,
  "documentRoot": "/",
  "url": "/html/index_128k.html",
  "enableServer": true,
  "enableNativeAPI": true,
  ...
}
```

**关键修改点：**
1. 将 `"documentRoot"` 从 `"/resources/"` 修改为 `"/"`
2. 将 `"url"` 从 `"/resources/index_128k.html"` 修改为 `"/html/index_128k.html"`

### 步骤 2：验证资源映射配置

确保 `cli.resources` 部分正确配置了资源映射：

```json
"cli": {
  "binaryName": "gigatron-128k",
  "resourcesPath": "/resources/",
  "extensionsPath": "/extensions/",
  "clientLibrary": "/resources/neutralino.js",

  "clientVersion": "6.3.0",
  "frontendLibrary": {
    "patch": true
  },
  "resources": [
    {
      "directory": "/html/",
      "recursive": true,
      "exclude": [],
      "include": ["**/*"]
    },
    {
      "directory": "/roms/",
      "recursive": true,
      "exclude": [],

    },
    {
      "directory": "/gt1/",
      "recursive": true,
      "exclude": [],

    },
    {
      "directory": "/resources/",
      "recursive": true,
      "exclude": [],
      "include": ["**/*"]
    },
    {
      "file": "/sd.vhd",
      "exclude": []
    },
    {
      "file": "/dev128k.rom",
      "exclude": []
    },
    {
      "file": "/favicon.ico",
      "exclude": []
    }
  ],
  ...
}
```

### 步骤 3：清理并重新构建

执行以下命令清理旧的构建文件并重新构建：

```bash
# 清理旧的构建文件
neu clean

# 重新构建应用程序
neu build
```

### 步骤 4：测试应用程序

构建完成后，测试应用程序是否正常运行：

```bash
# 在开发模式下测试
neu run

# 如果开发模式正常，测试打包后的应用程序
cd dist/gigatron-128k
./gigatron-128k-win_x64.exe  # Windows
# 或对应的平台可执行文件
```

## 备选方案

如果上述方法仍然无法解决问题，可以尝试以下备选方案：

### 方案 A：使用相对路径

修改配置文件使用相对路径：

```json
{
  "documentRoot": "./html/",
  "url": "./index_128k.html",
  ...
}
```

### 方案 B：直接指定文件路径

修改配置文件直接指定文件路径：

```json
{
  "documentRoot": "/html/",
  "url": "/index_128k.html",
  ...
}
```

### 方案 C：复制文件到 resources 目录

1. 创建 `resources` 目录（如果不存在）
2. 将 `html/index_128k.html` 复制到 `resources/` 目录
3. 修改配置文件：

```json
{
  "documentRoot": "/resources/",
  "url": "/index_128k.html",
  ...
}
```

## 验证修复

修复后，应用程序应该能够正常启动并显示 Gigatron 128K 模拟器界面，而不是 404 错误页面。

## 常见问题

### Q: 为什么会出现路径重复的问题？

A: 在原始配置中，`documentRoot` 设置为 `/resources/`，而 `url` 也设置为 `/resources/index_128k.html`，这导致最终路径变成 `/resources/resources/index_128k.html`，造成路径重复和文件找不到的问题。

### Q: 如何确认资源文件是否正确打包？

A: 可以通过以下方式确认：

1. 检查 `neutralinojs.log` 文件中是否还有资源加载错误
2. 在开发模式下运行 `neu run`，确认应用程序正常工作
3. 检查打包后的应用程序大小，确保包含了所有资源文件

### Q: 如果修改后仍然有问题怎么办？

A: 如果修改后仍然有问题，可以尝试：

1. 完全删除 `dist` 目录后重新构建
2. 检查是否有其他配置文件覆盖了这些设置
3. 查看 `neutralinojs.log` 文件获取更详细的错误信息
4. 考虑使用最新版本的 Neu CLI 和 Neutralinojs

## 总结

这个 404 错误主要是由于配置文件中的路径设置不正确导致的。通过修改 `documentRoot` 和 `url` 配置，确保路径映射正确，可以解决这个问题。建议在修改配置后先在开发模式下测试，确认无误后再进行打包构建。
