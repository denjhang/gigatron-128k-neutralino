# Neu 打包应用 404 错误分析文档

## 问题描述

当使用 Neu 打包的 Gigatron 128K 应用程序启动后，显示以下错误信息：

```
找不到以下 Web 地址的网页： http://127.0.0.1:62531/index_128k.html
HTTP ERROR 404
```

## 错误分析

### 1. 根本原因

根据 `neutralinojs.log` 文件中的错误信息，问题的根本原因是：

```
ERROR 2025-12-01 11:23:27,812 NE_RS_UNBLDRE: Unable to load application resource file /resources/resources/index_128k.html
ERROR 2025-12-01 11:24:57,115 NE_RS_UNBLDRE: Unable to load application resource file /resources/index_128k.html
```

应用程序无法加载资源文件 `/resources/index_128k.html`，这导致了 404 错误。

### 2. 配置文件分析

在 [`neutralino.config.json`](neutralino.config.json) 中，有以下关键配置：

```json
{
  "documentRoot": "/resources/",
  "url": "/resources/index_128k.html",
  "enableServer": true,
  "port": 0,
  ...
}
```

这些配置表明：
- 应用程序的文档根目录设置为 `/resources/`
- 入口文件设置为 `/resources/index_128k.html`
- 启用了内置服务器
- 端口设置为 0（表示使用随机可用端口）

### 3. 资源映射问题

在 [`neutralino.config.json`](neutralino.config.json:48-85) 的 `cli.resources` 部分，定义了资源映射：

```json
"resources": [
  {
    "directory": "/html/",
    "recursive": true,
    "exclude": [],
    "include": ["**/*"]
  },
  ...
]
```

这个配置将 `/html/` 目录下的所有文件映射到应用程序的 `/resources/` 目录。然而，根据错误日志，系统在尝试访问 `/resources/index_128k.html` 时失败了。

### 4. 可能的原因

1. **资源打包问题**：在打包过程中，`html/index_128k.html` 文件可能没有正确地被打包到 `resources.neu` 文件中。

2. **路径映射问题**：虽然配置中指定了将 `/html/` 目录映射到 `/resources/`，但实际打包时可能存在路径解析问题。

3. **文件访问权限问题**：打包后的应用程序可能没有足够的权限访问资源文件。

4. **资源文件缺失**：在打包过程中，某些必要的资源文件可能被遗漏。

## 解决方案

### 1. 验证资源文件存在

首先确认 `html/index_128k.html` 文件确实存在于项目中：

```bash
ls -la html/index_128k.html
```

### 2. 重新构建应用程序

尝试重新构建应用程序，确保所有资源都被正确打包：

```bash
neu build
```

### 3. 检查资源映射配置

确保 [`neutralino.config.json`](neutralino.config.json) 中的资源映射配置正确：

```json
"resources": [
  {
    "directory": "/html/",
    "recursive": true,
    "exclude": [],
    "include": ["**/*"]
  },
  ...
]
```

### 4. 修改配置文件

如果问题仍然存在，可以尝试修改配置文件，直接指定入口文件的完整路径：

```json
{
  "documentRoot": "/",
  "url": "/html/index_128k.html",
  ...
}
```

或者：

```json
{
  "documentRoot": "/html/",
  "url": "/index_128k.html",
  ...
}
```

### 5. 检查打包后的资源

可以使用工具检查 `resources.neu` 文件，确认 `index_128k.html` 是否被正确打包：

```bash
# 如果有 neu inspect 命令
neu inspect dist/gigatron-128k/resources.neu
```

### 6. 使用开发模式测试

在开发模式下测试应用程序，确认资源文件是否可以正确加载：

```bash
neu run
```

## 预防措施

1. **构建前验证**：在构建前，确保所有必要的资源文件都存在于正确的位置。

2. **使用绝对路径**：在配置文件中使用绝对路径，避免路径解析问题。

3. **详细日志**：在开发过程中启用详细日志，以便更好地诊断问题。

4. **资源完整性检查**：在打包后，检查资源文件的完整性，确保所有必要的文件都被包含。

## 结论

Neu 打包应用显示 404 错误的主要原因是资源文件 `index_128k.html` 没有被正确打包或路径映射不正确。通过检查配置文件、重新构建应用程序和修改路径配置，可以解决这个问题。

建议在开发过程中使用 `neu run` 命令进行测试，确保应用程序在开发模式下正常工作，然后再进行打包构建。
